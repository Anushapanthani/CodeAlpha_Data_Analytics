# CodeAlpha Data Analytics Internship

## Overview
This repository contains the data analytics projects completed as part of the CodeAlpha Data Analytics Internship.

## Tasks Completed

### Task 1 - Web Scraping
Scraped quotes and author names from a website using Python, Requests and BeautifulSoup.

### Task 2 - Exploratory Data Analysis
Performed basic data analysis on student performance data using Pandas.

### Task 3 - Data Visualization
Created visualizations to understand the relationship between study hours, attendance and final scores using Matplotlib.

### Task 4 - Sentiment Analysis
Analyzed customer reviews and classified them into Positive, Negative and Neutral sentiments.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Requests
- BeautifulSoup

## Project Files
- `task1_web_scraping.py` - Web scraping
- `task2_eda.py` - Exploratory Data Analysis
- `task3_visualization.py` - Data Visualization
- `task4_sentiment.py` - Sentiment Analysis

## Datasets
- `scraped_quotes.csv`
- `student_performance.csv`
- `reviews.csv`

## Visualizations
The repository contains charts generated from the data analysis and sentiment analysis tasks.

## Conclusion
These projects demonstrate basic practical skills in web scraping, data cleaning, exploratory analysis, data visualization and sentiment analysis using Python.
